# Домашнее задание: Функции

## Зависимости

Проект использует только встроенные модули Python (csv, collections). Сторонние библиотеки не требуются.
Для проверок использовался `flake8` и `mypy`.

## Как запустить

Установите Python 3. Если он уже установлен, то, находясь в папке с проектом и исходным файлом `Corp_Summary.csv`, выполните команду:
python omd2.py
