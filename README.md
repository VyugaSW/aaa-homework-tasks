# Домашнее задание: Классы

## Зависимости

Проект использует только встроенные модули Python (`math`). Сторонние библиотеки не требуются.
Для проверок стиля кода использовался `flake8 и mypy`.

## Как запустить

Установите Python 3. Если он уже установлен, то, находясь в папке с проектом, выполните команду:

```bash
python omd.py
```
