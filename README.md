# Домашнее задание

## Зависимости

Проект использует только встроенные модули Python (collections). Сторонние библиотеки не требуются.
Для проверок использовались `flake8` и `mypy`.

## Как запустить

Установите Python 3, если он уже установлен, то, находясь в корневой папке проекта, выполните команду:
python omd.py
