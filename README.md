# Анализ данных о Нобелевских лауреатах

## Зависимости

Для работы проекта требуется Python 3.9+.

Используются сторонние библиотеки:

- `requests` - для загрузки данных из API Нобелевской премии
- `matplotlib` - для построения графиков в ноутбуке
- `jupyter` - для запуска ноутбука
- `pytest` - для запуска unit-тестов

Для проверки стиля кода использовался `flake8` и `mypy`.

Установить зависимости можно командой:

```bash
pip install requests matplotlib jupyter pytest
```

## Как запустить

Убедитесь, что установлен Python 3.9+ и зависимости из раздела выше.

Находясь в корневой папке проекта:

1. Запуск тестов:

```bash
pytest
```

2. Запуск Jupyter Notebook:

```bash
jupyter notebook
```

После запуска откройте файл ноутбука с заданием и выполните все ячейки по порядку (`Kernel -> Restart & Run All`).
